# Typographie HainoFlow

## Famille primaire - interface et communication

Recommandation : **Manrope** (Google Fonts, licence libre OFL). Fallback : `Inter, DejaVu Sans, Arial, sans-serif`.

- H1 : 48-64 px, graisse 700, interligne 1.08.
- H2 : 32-44 px, graisse 700, interligne 1.15.
- H3 : 24-30 px, graisse 650-700.
- Corps : 16-18 px, graisse 400, interligne 1.55.
- Libelle UI : 13-15 px, graisse 600.

## Famille secondaire - signature premium

Recommandation : **Cormorant Garamond** pour les titres institutionnels, jamais pour les champs, prix ou petits textes. Fallback : `DejaVu Serif, Georgia, serif`.

## Regles

- Ne pas utiliser plus de deux familles dans un meme support.
- Ne jamais descendre sous 12 px sur le web ou 8 pt en impression.
- Les nombres, montants et tableaux restent en sans-serif pour la lisibilite.
